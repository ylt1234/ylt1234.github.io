制作模拟真实情况的样本

设定的线性回归方程是y=2×X1-3.4×X2+4.2

  • torch.tensor：创建张量（向量），并且没有行向量列向量的区别,一般用于权重。如果想要生成行/列向量要在每一行结束多套一层方括号，比如行向量 torch.tensor([[2, -3.4]])，列向量 torch.tensor([[2], [-3.4]])
  • torch.normal(0, 1, (num_examples, len(true_w)))torch.norma：正态分布采样函数，生成正态分布均值为0，标准差为1，形状为(num_examples, len(true_w))，在这里就是1000行2列的矩阵，每一行就是生成的X1、X2
  • torch.matmul：矩阵乘法运算，features是1000×2的张量，torch会自动把一维向量当中列向量，也就是true_w被当成2×1的张量，乘完就是1000×1的张量。
  • 按照常规的矩阵加法，1000×1的张量是无法与标量4.2相加的。这里用到了torch的广播机制，他会自动把小张量扩大成大张量然后相加，加完lables还是一个1000×1的张量，每一行的一个元素表示完美符合线性规律的纯净标签并且没有任何误差
  • labels += torch.normal(0, 0.01, labels.shape)：真实情况样本不可能完全符合线性方程，所以要加入噪音；labels.shape是返回labels的形状，
  • labels.reshape：用来改变张量的形状，但是不改变张量的数值和元素总数。（）里填的是要改变成什么形状，这里-1表示自动匹配原本的形状，所以这里labels.reshape(-1, 1)，相当于labels.reshape(1000, 1)。

调用框架内置预定义好的层

  • 把torch.nn库引入当前作用域，之后用nn可以方便。
  • nn.Sequential()：是一个按顺序串联神经网络层的容器。
    • 顺序串联：是前向传播流程，即数据从第一层输入->第一层输出->第二层输入……数据没有分支、跳跃、多路汇合等。并且是按顺序串联，所以可以像数组一样按索引取出某一层。
    • 容器：是一个管理与调度神经网络的盒子。可以调用 net(X)就可以直接得到最终输出结果，不用逐层调用。并且可以使用 net.parameters()一次性取出所有的可训练参数（权重、偏置），不用逐层收集。
    • 如果想在容器内放多层可以这么写
  • nn.Linear()：全连接线性层。nn.Linear(2, 1)，2表示输入特征的维度（X1、X2），1表示输出特征的维度（Y），就相当于Y=a1×X1+a2×X2+b。在线形层内部是张量计算，就是 y = xW^T + b，x形状是（10，2），w形状是（输入维度，输出维度）即（1，2），y形状是（10，1），b形状为（输出维度，）即（1，）。
  • （1，）的含义是一维张量，相当于数学中长度为1的向量，无行列之分；（1，1）的含义是二位张量，相当于数学中的1×1的矩阵，有行列之分。PyTorch训练的约定标准是所有批量的特征，标签，输出都必须保持（样本数，特征数/标签数）的二维格式。而模型原生参数和单组的参数一般只用一维张量。

    • 不带 _：生成一个全新张量作为结果，有返回值

    • eg:

  • init.normal_(tensor, mean=0.0, std=1.0)：用指定均值和标准差的的正态分布，来随机填充目标张量的所有元素。tensor：待初始化的目标张量（一般是权重/偏置），mean：正态分布的均值，默认为0，std：正态分布的标准差，默认为1。

  • init.constant_(tensor, val=0)：用指定固定常数值，来填充目标张量的所有元素。

  • 为什么权重要赋正态分布的值，而不是像偏置一样赋一个固定值：因为两个参数如果赋了相同的初始值，而模型是使用梯度下降更新参数，就会导致每次更新的结果都一样，两个参数就是永远一定一样了，而实际上最适合的参数不一定两个数值一样

训练过程代码

  • 外层循环（轮次控制循环）：

    • for epoch in range(num_epochs)：这里是range（3），就是循环三次，每轮epoch的值依次是0、1、2。
    • 这里3此循环的含义是完成3轮学习

  • 内层循环（批次循环）：

    • data_iter：前面使用data.DataLoader制作好的小批量数据，每次循环都会自动取出一批数据，X为当前批次的输入特征，y为当前批次对于的真实标签

  • 批次内：四步标准训练流程

    • 前向传播+计算损失：

      • 前向传播：先执行 net(x)，把当前批次的特征输入模型，然后用当前的权重和偏置计算出预测值
      • 计算损失：再执行 loss(预测值,真实值)用均方误差计算这批数据的平均损失

    • 清零梯度：

      • 作用：把优化器管理的所有参数的梯度值全部重置为0
      • 为什么会有这一步：因为PyTorch会累加梯度，如果不清零就会把上一轮的梯度累加进来

    • 反向传播计算梯度

      • 从损失值 l出发，沿着计算图从后往前进行链式求导，自动算出每一个可训练参数对应的梯度，并把梯度自动存入每个参数的 .grad属性中。比如这一步执行完之后，net[0].weight.grad和 net[0].bias.grad就有了具体数值

    • 优化器更新参数

      • 优化器读取每个参数当前的梯度，按照SGD的更新公式 参数新值 = 参数旧值 - 学习率 × 损失对该参数的梯度,自动更新所有的权重和偏置的数值

  • 每轮结束：计算并打印整体损失

  • 为什么要再用全部的训练集计算一次损失：为了对比每一次训练完的结果到底有没有变好。

比较真实参数和模型训练得到的参数

理论

Q1：梯度下降是什么？

以最简单的找一个y=wx+b方程为例

假设机器学习是想要找到描述这五个点最合适的线，其实目标就是找一根线，使得每一个点里这根线的误差总和最小。但是注意不是最短距离最近，因为误差只是在相同x的情况下y差多少

误差肯定不能有的正有的负直接相加，比如这个直接相加-0.3+0.1+1-0.1-0.7=0，就会误以为是完全拟合了。所以最先想到的是绝对值相加，但是用绝对值相加会产生一个问题，后面可以感受到。常用的是均方误差，就是把每个点的误差进行平方相加再取平均，他的结果叫做损失。

先固定b，只变化w。得到以w为x轴，损失值作为y轴的开口向上的抛物线。因为

其中只有w是未知数，所以展开之后是一个关于w的一元二次方程，如下图：

可见一定是有一个损失最小的斜率，在抛物线的凹点，不过机器又没有办法模拟出完整的这一条抛物线，只能知道当前的权重和偏置对于的损失值。但是可以发现如果当前的斜率是负的，那么损失最小的点就在当前点右边，如果斜率是正的，那么损失最小的点就在当前点的左边。所以只要用斜率定义，在w间隔特别小的情况下，(j1-j2)/(w1-w2)为正为负就能判断要往大还是往小更新w。

那要更新步长是多少呢？太大会导致一直在凹点左右震荡却靠近不了，太小会导致太慢。可以发现斜率绝对性越大的地方，需要更新的比较大，斜率绝对值越小的地方，需要更新的比较小，所以可以使用动态更新的方法，规定步长=a×导数（a为学习率），即 参数新值 = 参数旧值 - 学习率 × 导数。

以上是固定b的情况，如果要考虑b的话，坐标轴就不是简单的抛物线了，要再加一条b轴，大约长这样

不过做法类似，可以分别寻找w要怎么变，b要怎么变。找w变时就固定b，相当于求w的偏导数；找b变时就固定w，相当于求b的偏导数。把两个偏导数打包到一个向量中，这个向量就叫梯度，即上面的 参数新值 = 参数旧值 - 学习率 × 损失对该参数的梯度

Q2：计算图是什么

用最简单的单特征线性回归 + 均方误差为例，模型预测：ŷ=wx+b，损失计算：L=(ŷ-y)^2。

计算图结构如图：

代码中执行 net(X)和 loss(y_pred,y)的过程就是搭建这个图的过程，每做一次张量运算，就往里面新增一个节点和对应的边。计算图的最大作用的就是让反向传播可以自动完成，调用 l.backword()时，PyTorch就会从根节点（损失L）出发，往回遍历，每经历一个运算节点，就用链式法则求出梯度，并传给前一个节点，直到所有叶子节点都求出梯度。

反向传播过程：（用d来表示偏导符号）

  1. 从损失出发：初始梯度dL/dL=1
  2. 平方节点：dL/dz2=2×z2（z2的梯度就是2z2）
  3. 减法节点：dz2/dŷ=1，dz2/dy=-1（ŷ的梯度就是1×2z2=2z2）
  4. 加法节点：dŷ/dz1=1，dŷ/db=1（z1的梯度就是1×2z2=2z2，b的梯度就是1×2z2=2z2）
  5. 乘法节点：dw/dz1=x（w的梯度就是x×2z2=2xz2）
  6. 这样就可以得到权重w和偏置b的梯度，就可以更新参数了。最后只有叶子节点会保留梯度，其余节点自动释放节约内存。

数据集下载与基础信息查看

  • trans = transforms.ToTensor()：用于PIL图片或者numpy数组进行预处理（大多数情况下图片输入进来学习都要有这一步转换过程）
    • 1：原始PIL/numpy图片是uint8类型的，先转成float32浮点类型。
    • 2：原始PIL/numpy图片的存储格式是（高度、宽度、通道数），转成PyTorch约定的输入格式（通道数，高度，宽度）
    • 原始PIL/numpy图片的像素取值范围是0-255，转成0.0-1.0的浮点数。因为神经网络对小浮点数输入训练更加稳定，因为数值大，梯度会爆炸，loss不好收敛。如何变？直接除以255即可。
  • torchvision.datasets.FashionMNIST：torchvision内置的Fashion-MNIST数据集可以自动下载，读取数据集。
    • Fashion-MNIST是德国电商Zalando发布的公开图像数据集，有60000 张训练图片、10000张测试图片。图片格式全部是28×28像素的单通道灰度图，像素值范围0~255。这个数据集的图片一共对应10种服饰类型，任务是目标是输入一张图片，判断它属于这10个类别中的哪一个。
    • root="../data"：数据集保存的本地路径。train=True/False：True加载训练集，False加载测试集。transform=trans：图片加载进来的时候自动预处理变换，trans就算上一行定义的变换方法。download=True：true就是先看本地有没有数据集，有的话直接读取，没有的话下载；flase：也是先看本地有没有数据集，有的话直接读取，没有的话报错。
  • len(mnist_train), len(mnist_test)：返回训练集和测试集的样本总数。
  • mnist_train[0][0].shape：返回第一张图片的形状。这里会返回（1，28，28），即（通道数，长度，宽度）。

标签映射与图像批量可视化

  • 数据集的原始标签是0-9，不便于理解，用这个函数把数字映射成对应的服饰名称。意思是返回 text_labels[int(i)]，而其中i是在labels中。为什么要 int(i)？因为labels中是张量形式，所以i也是张量形式。

  • 参数列表：imgs：图片列表，是张量形式。num_rows：画布多少行子图。num_cols：画布一共有多少列子图。titles=None：每张图片对应的文字标题，不传就默认没有。scale：单张子图的放大系数，控制整个图的大小。

  • _, axes = plt.subplots(num_rows, num_cols, figsize=figsize)：

    • plt.subplots：创建一张大图，里面切分出num_rows × num_cols个小坐标系，这个大图一共有figsize大。如果不写figsize，就默认大图用默认尺寸创建画布，但是如果切分的小图太多，就会导致每个小图太小看不清。这样设置就可以保证每个小图都是scale × scale大小。
    • plt.subplots一共有两个返回值，第一个返回值fig代表整张画布，负责保存图片、设置总标题、调整整体背景、间距等。第二个返回值axes代表所有切分好的子图，负责画图、改标题、隐藏坐标轴等。并且第二个返回值可以用索引（axes[0][0]）访问每一个小图。
    • -：是python的约定，这个变量接收，但不用。这里不需要用到第一个返回值，所有用_来接收。

  • axes.flatten()：把二维的axes数组拉平成一维数组。好处是后面循环遍历不需要双重for循环，直接一个循环就可以依次拿每一个子图。

  • for i, (ax, img) in enumerate(zip(axes, imgs)):：

    • zip(A,B)：把两个可迭代的对象按位置配对。eg：axes=[ax0,ax1],imgs=[img0,img1]。zip之后就变成(ax0,img0),(ax1,img1)。
    • enumerate(可迭代对象)：每一轮返回（序号，迭代的元素）。比如 for i,item in enumerate([(ax0,img0),(ax1,img1)])，item就是(ax0,img0),(ax1,img1)

  • ax.axes.get_xaxis().set_visible(False),ax.axes.get_yaxis().set_visible(False)：把每张小图的x，y轴全部隐藏，只保留图片。

  • return axes：返回所有的子图对象，方面后续继续修改画布。

Softmax回归

是什么

softmax回归虽然名字里有回归，但是实际上用于多分类任务，比如输入图片，判断它属于猫/狗/鸟。softmax回归就是用线性模型计算出每个类别的分类，然后再把分数转化成属于每个类别的概率。

Softmax 的公式是：

为什么叫softmax：含义是软化的最大值选择函数

流程

  1. 输入一张图片处理后有很多像素：x1，x2，…，xn

  2. 用线性模型来分布计算三个分数：

    1. o1=w1^T・x + b1
    2. o2=w2^T・x + b2
    3. o3=w3^T・x + b3

    假设模型算出来 猫：2.0、狗：1.0、鸟：-1.0

  3. 使用softmax公式把算出来的结果转换成概率：

    1. e^2=7.39，e^1=2.72，e^-1=0.37。然后全部加起来7.39+2.72+0.37=10.48。
    2. 然后分别除以总和：P（猫）=7.39/10.48=0.705，P（狗）=2.72/10.48=0.260，P（鸟）=0.37/10.480.035

  4. 损失函数使用的是交叉熵损失：L=-logP(真实类别)

  5. 更新权重的方法和前面的线性回归一模一样：w新=w旧-a×dL/dw（a是学习率，d来代替偏导符号）。理由也一样，因为梯度是损失值增长最快的方向，而我们要损失值变小，所以是往梯度的反方向走。

初始化模型

  • nn.Sequential：顺序容器，按括号里的顺序依次执行每一层。
  • nn.Flatten()：维度展平层，他的作用是索引为0的维度保持原样，索引为1的维度开始直到最后一个维度，全部展平成一维。在这输入是形状为（batch_size，1，28，28）【（批次，通道，高，宽）】的张量，那就会被展平到（batch_size，1×28×28）即（batch_size，784）维的张量。
    • 为什么要展平：因为全连接层只会认为最后一维是特征维度，只与最后一维进行计算。前面都认为是批次向量，不参与运算。

  • nn.Linear(784, 256)：第一个全连接层（隐藏层），输入维度784（对应展平后图像的维度），输出维度256。
  • nn.Linear(256, 10)：输出层。输入维度256，输出维度10，对应10个服饰类别。
  • 注意这里不要加Softmax，因为下面CrossEntropyLoss内部已经做了log-softmax
  • 自定义 init_weight函数遍历网络每一层，如果该层是全连接层，就用均值为0，标准差为0.01的正态分布随机初始化它的权重参数。代码里面没有0，为什么是均值为0，因为它的默认参数是 torch.nn.init.normal_(tensor, mean=0.0, std=1.0)，不填就是默认参数。
  • net.apply(init_weights)：apply会遍历网络中的所有层，把 init_weight函数应用到每一个模块上，完成全局初始化。
  • 偏置这里没有设置就是使用默认的0。

定义损失函数和优化器

  • nn.CrossEntropyLoss(reduction='none')：CrossEntropyLoss是交叉熵损失函数，后面参数 reduction='none'的意思是，比如有256张图片，那么就会有256个loss，none就是保留这256个loss，不把他们求平均或者求和。
  • torch.optim.SGD(net.parameters(), lr=0.1)：这是优化器。 SGD就是Stochastic Gradient Descent，中文是随机梯度下降。
